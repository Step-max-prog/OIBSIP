# Login Authentication System 🔐

## Project Overview

This project is a responsive Login Authentication interface created as part of my **Oasis Infobyte Web Development Level 2 Internship – Task 4**.

The project demonstrates a front-end login system with form validation and user interaction using HTML, CSS, and JavaScript.

## Features

- Responsive login form
- Email input validation
- Password validation
- Minimum password length check
- Login success message
- Forgot Password interaction
- Remember Me checkbox
- Mobile-friendly design
- Clean and simple user interface

## Technologies Used

- **HTML5** – Structure of the login page
- **CSS3** – Styling and responsive design
- **JavaScript** – Form validation and user interaction

# Tribute Page 🌹

## Project Overview

This project is a responsive tribute page created as part of my **Oasis Infobyte Web Development Level 2 Internship – Task 2**.

The tribute page is dedicated to my late mother, **Matilda Abena Dankwah**, who lived to the age of 56. The website was created to honor her memory and showcase her life, love, and lasting legacy.

## Features

- Responsive design for desktop and mobile devices
- Navigation bar with smooth scrolling
- Personal tribute section
- Biography section
- Life and family section
- Precious memories photo gallery
- Legacy section
- In Loving Memory section
- Responsive image layouts
- Mobile-friendly navigation
- Clean and elegant user interface

## Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout, animations, and responsive design

## How to Run the Project

1. Download or clone the project repository.
2. Open the `WebDev-L2-T2-TributePage` folder.
3. Open `index.html` in a web browser.
4. Use the navigation bar to move between different sections of the page.

## Responsive Design

The tribute page is designed to adapt to different screen sizes.

It has been tested on both:

* Desktop screens
* Mobile/responsive screens

The layout automatically adjusts the navigation, images, text, and memory gallery for smaller devices.

# To-Do Web App 📝

## Project Overview

This project is a responsive To-Do Web App created as part of my **Oasis Infobyte Web Development Level 2 Internship – Task 3**.

The application allows users to add tasks, mark tasks as completed, undo completed tasks, and delete tasks. It also supports adding tasks using the Enter key.

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Add tasks using the Enter key
- Empty-task validation
- Responsive design for desktop and mobile devices
- Clean and simple user interface

## Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – App functionality and user interaction

# Personal Portfolio Website

## Overview

This project is a personal portfolio website created as part of the Oasis Infobyte Web Development Internship.

The website showcases my background, technical skills, academic and practical projects, experience, and contact information.

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- CSS Flexbox
- CSS Grid
- Responsive Web Design

## Features

- Responsive navigation bar
- Personal hero/profile section
- About Me section
- Technical skills section
- Projects section
- Experience section
- Contact information
- GitHub and LinkedIn links
- Responsive design for desktop and mobile devices
- Smooth section navigation

# Temperature Converter 🌡️

## Project Overview

This project is a simple and responsive Temperature Converter website developed as part of my **Oasis Infobyte Web Development Level 1 Internship – Task 3**.

The application allows users to convert temperatures between **Celsius, Fahrenheit, and Kelvin**.

## Features

* Convert between Celsius, Fahrenheit, and Kelvin
* Simple and user-friendly interface
* Instant conversion using JavaScript
* Clear button to reset the converter
* Responsive design for mobile and desktop devices
* Input validation for empty temperature fields

## Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and responsive design
* **JavaScript** – Temperature conversion functionality

## Temperature Conversions

The converter supports:

* Celsius → Fahrenheit
* Celsius → Kelvin
* Fahrenheit → Celsius
* Fahrenheit → Kelvin
* Kelvin → Celsius
* Kelvin → Fahrenheit

## How to Use

1. Enter a temperature value.
2. Select the unit you are converting **from**.
3. Select the unit you are converting **to**.
4. Click the **Convert** button.
5. The converted temperature will be displayed.
6. Click **Clear** to reset the converter.

## Example

If you enter:

**25°C → Fahrenheit**

The result will be:

**77.00 °F**

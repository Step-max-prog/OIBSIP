# Calculator 

## Project Overview

This project is a functional and responsive calculator developed as part of my **Oasis Infobyte Web Development Level 2 Internship – Task 1**.

The calculator allows users to perform basic mathematical operations through a simple and user-friendly interface.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Percentage calculations
* Decimal calculations
* Clear (AC) button
* Delete (DEL) button
* Error handling for invalid calculations
* Responsive design for different screen sizes

## Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and responsive design
* **JavaScript** – Calculator functionality and calculations

## How to Use

1. Open the calculator in a web browser.
2. Enter numbers using the calculator buttons.
3. Select an arithmetic operator.
4. Press `=` to calculate the result.
5. Use `AC` to clear the display.
6. Use `DEL` to remove the last entered character.

## Example Calculations

```text
7 + 5 = 12

8 × 6 = 48

20 ÷ 4 = 5

10.5 + 2.5 = 13
```

The calculator is designed to work on both desktop and mobile screen sizes.

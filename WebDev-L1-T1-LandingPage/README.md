# Afriqube Landing Page

## Overview

This project is a responsive landing page created for **Afriqube**, an African fashion brand. It was developed as part of the **Oasis Infobyte Web Development Internship – Level 1 Task 1**.

The landing page is designed to showcase Afriqube's fashion collection while presenting the brand's identity, products, and contact information in a clean and modern layout.

## Technologies Used

* HTML5
* CSS3
* Font Awesome
* CSS Flexbox
* CSS Grid
* Responsive Web Design

## Features

* Sticky navigation bar
* Hero section with brand introduction
* Call-to-action buttons
* Product collection section
* About Afriqube section
* Why Afriqube section
* Contact/call-to-action section
* Footer with social media icons
* Responsive design for desktop and mobile devices
* Consistent black, gold and cream colour scheme

## Sections

### Home

Introduces the Afriqube brand with the tagline:

**"Wear Culture, Wear Confidence."**

### Collection

Displays selected Afriqube fashion collections, including:

* Ankara Shirts
* Backless Dresses
* Top & Pleated Sets

### About Afriqube

Provides a brief introduction to the brand and its connection to African culture and modern fashion.

### Why Afriqube

Highlights the brand's focus on:

* African Identity
* Easy-to-style fashion
* Confidence

### Contact

Provides a call-to-action for customers interested in exploring the collection and contacting Afriqube.

## Responsive Design

The website was designed to adapt to different screen sizes, including desktop, tablet and mobile devices.

The layout uses CSS Flexbox, CSS Grid and responsive media queries to ensure that the content remains accessible and visually organized across different devices.
